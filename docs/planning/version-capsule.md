# 版本胶囊设计

侧栏底部采用“类型图标 + 完整当前版本号”，有更新时在右上显示外置金色角标。胶囊整体为一个按钮，只打开更新页，不触发检查、下载或安装。

## 状态与数据

| 已安装构建 | 主体 | 类型图标 | 更新提示 |
| --- | --- | --- | --- |
| 正式版 | 墨青底、浅色文字 | `shield-check` | 无角标 / 金色“有更新” |
| 预览版 | 浅金底、墨青文字 | `flask-conical` | 无角标 / 金色“有更新” |

- `About.IsPreviewBuild` 来自 `LauncherInformation.CurrentBuild.Channel`，表示当前运行构建，不表示设置中选中的更新渠道。切换渠道不改变主体类型或当前版本。
- 主体原样绑定 `About.DisplayVersion`，例如 `v0.1.0`、`v0.1.0p128.2`。开发构建保留现有说明；UI 不解析 `p`、拼接版本或附加 hash。
- 角标绑定 `About.HasUpdateReminder`，与当前版本类型独立。没有角标不代表已是最新版。检查中、失败、下载、取消及查看更新页沿用现有提醒保留规则。
- Tooltip 与辅助名称包含当前安装类型、完整版本、是否有更新、已知目标版本及“打开更新页面”；失败时说明保留上次结果。目标版本未知时只显示“有更新”。

## 几何与字体

尺寸均为 WPF DIP，按系统 DPI 渲染，不依赖 WebView。

| 元素 | 定稿值 |
| --- | --- |
| 主体 | 高 36，圆角 18，边框 1；左内距 6、右内距 10 |
| 图标底盘 | 22×22，圆角 11；内部图标 16×16，原始画布 24×24，描边 1.8，圆端点、圆连接 |
| 版本 | 与底盘间距 7；Consolas 优先的等宽字体，14、Normal，文本盒和行高 20 |
| 角标 | 高 20，边框 1，水平内距 6；圆角左上/右上/右下/左下为 10/10/10/3 |
| 角标文字 | “有更新”，12、Medium，行高 18；没有刷新图标、没有动画 |
| 角标位置 | 相对主体顶部 -15、右侧 -6；不参与主体宽度计算 |
| 整体位置 | 主体在侧栏水平居中，左右至少留 16；距窗口底部 28，与右侧内容区对齐 |
| 焦点 | 2 宽轮廓，距主体 3，颜色 `#B69761` |

完整版本单行常驻，不省略、不裁切、不换行、不缩字号。主体宽度为文本实测宽度加 47，不把示例宽度当上限。等宽字体依次回退至 Cascadia Mono、SFMono-Regular、Liberation Mono，中文开发构建说明使用 Microsoft YaHei UI。

WPF 按钮预留固定 52 高承托区和左右各 8 的空间，主体底部对齐；对称留白保持主体居中，角标的可见外伸区域仍在同一个按钮命中范围内。底部行按内容自动计高，按钮外距为左 8、上 8、右 8、下 28，容纳阴影与焦点；角标显隐不移动主体、版本和相邻布局。侧栏最小宽度 216，随长版本自然扩展，为完整版本保留真实布局空间；品牌图保持原有最大宽度，不随侧栏放大。右侧页面保留原有 800 宽小窗口布局的最小内容宽度 544，空间不足时横向滚动，避免极长版本挤掉页面控件。

| 部位 | 正式版 | 预览版 |
| --- | --- | --- |
| 主体渐变（上→下） | `#3B5C6A` → `#2E4C58` | `#F6EFDF` → `#EADEC4` |
| 文字 | `#FAF9F3` | `#294A57` |
| 边框 | `#7E9198` | `#B69761` |
| 图标底盘 | `#506F7A` | `#DFC99D` |
| 图标描边 | `#E9F0F1` | `#6A4D20` |
| 内顶高光 | 白色 16% | 白色 72% |

角标统一使用 `#EBBC61` → `#DBA33D` 渐变、`#422B0D` 文字、`#9F702B` 边框、`#FFE0A0` 内顶高光。主体阴影向下 1、模糊 3，颜色 `#1A2B31`、透明度 13%；角标阴影向下 1、模糊 2，颜色 `#3E2B0E`、透明度 15%。

浅色与深色主题保持上述定稿配色。高对比度主题改用系统窗口、文字与高亮颜色，保留盾牌/烧瓶形状和辅助名称，不依赖颜色区分类型。

## 实现与验收

- `src/Desktop/MainWindow.xaml`：单个原生 Button、完整版本、外置角标及自适应侧栏。
- `src/Desktop/Resources/VersionCapsule.xaml`：尺寸、字体、颜色、焦点与两枚 Lucide 图标的原始路径；完整许可见 `THIRD-PARTY-NOTICES.txt`。
- `tests/managed/UpdateReminderTests.cs`：提醒生命周期、四状态、渠道独立、未知目标、最长合法版本、100%～200% DPI 布局、角标稳定、窄内容区滚动；真实 HWND 的角标命中、焦点移动及 Enter/Space 路由键盘事件。
- `tests/managed/UiInteractionTests.cs`：胶囊导航及无额外更新操作；`tests/python/test_ui_contract.py`：结构约束。

运行 `python scripts/build.py --project managed`，再执行 `T7.ManagedHarness.exe --render-ui artifacts/ui-version-capsule`；托管程序位于 `artifacts/bin/T7.ManagedHarness/x64/Release/net48/`。四状态截图以 `capsule-stable-`、`capsule-preview-` 开头，深色、高对比度在对应子目录。

人工验收：Tab 只聚焦整个胶囊一次，焦点轮廓完整；Enter、Space 及主体/图标/版本/外伸角标的点击各导航一次。悬停或通过辅助名称可获取完整说明。在项目支持的 Windows 10/11 上检查系统缩放、长版本和小工作区，角标、阴影及焦点不与窗口边缘或导航重叠。
