## 首页补充验证

- 首页沿用公共外壳，登录默认进入 `/admin`，保留首次登录强制改密；品牌与导航均提供首页入口。
- 定向测试覆盖全量账户统计（含超过 50 个账户）、无数据、连接租约到期、凭证过期/撤销、认证版本变化及禁用账户；页面覆盖公告转义、群凭据异常、最近 5 条操作与非根上下文。
- Chromium 合成页面验证首页默认、空数据、已配置、凭据异常和 `/console` 上下文，覆盖 1920 / 1440 / 992 / 768 / 320 CSS px：未发现整页横向溢出、脚本错误或 CSP 违规。窄屏导航通过键盘展开与收起，当前页标记为“首页”。截图位于本地 `artifacts/admin-ui/home-1440.png` 和 `home-320.png`。

## 分组导航与面包屑补充验证

- 一级顺序及二级入口按当前规范；内容页提供唯一的面包屑导航，详情页可返回列表，子页保留所属分组选中态。
- 玩家操作记录、系统操作记录暂显示“建设中”，定向测试确认不调用审计查询；已有全部记录保留。未新增日志分类或数据库变更。
- `AdminUiTest`、`SecurityFiltersTest`、`WebErrorsTest` 共 21 项定向测试通过。Chromium 验证 1440 / 992 / 768 / 320 CSS px 下二级菜单、Enter / 方向键 / Esc、非根上下文跳转与面包屑，无整页横向溢出或脚本/CSP 错误。截图：本地 `artifacts/admin-ui/navigation-1440.png`、`navigation-320.png`。
