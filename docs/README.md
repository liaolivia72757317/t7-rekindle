## 文档分工

- 使用说明描述当前用户可见的行为和限制；架构、运行契约描述当前实现。
- 实施计划定义阶段目标和验收条件；任务清单记录已有基础与待完成事项。
- “已有实现”表示代码已存在，“自动化覆盖”表示仓库有相应用例；某次构建是否通过，以该提交的测试结果为准。
- 真实客户端验收单独记录。合成报告中的 `realClient=false` 表示未启动真实客户端，不代表完整游戏流程可玩。
