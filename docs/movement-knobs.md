# 移动开关（`level.ini` 的 `[move]` 段）

适用对象：客户端权威移动（宿主注入 `runtimeMovement=True`）下的 Python 脚本。这五个键决定**服务端要不要往客户端回写移动状态**，默认值就是实机跑通的那一套（走路不后退），不写 `level.ini` 也生效。

## 为什么需要这五个开关

客户端权威模式下，位置和朝向由客户端每帧上报，服务端只记一本账。问题是服务端发的**任何带 `position` 的移动报文**都会让客户端按回账本里的那个点，而账本只在收到上报时推进 —— 两次上报之间它最多多滞后一个上报间隔（外推上限 350 ms）。发得越频繁，人越容易被拽回旧点，玩家看到的就是「走一下退一下」「按 W 变后退」。

这五个键逐个管住这些出口：总闸之外，「平时报走/跑」「松手补停」「蹲跳带位置」三个口子分开开关，出问题能一行一行退回去。

## 键与取值

| 键 | 默认值 | 打开之后（老口径） |
| --- | --- | --- |
| `input_sync` | `on` | `off` = 只记账（位置/朝向/按键），一条帧都不发，连 54 号滞空闸门也不发；下面四个键随之全部无效 |
| `cc_move_mirror` | `off` | 按键或快跑**变化**那一拍跟发一条带方向的走/跑驱动帧（38 号，带位置）；起步那一拍还会排一个 2 s 定时器补「跑」档 |
| `cc_jump_state` | `stop` | `mirror` = 蹲/跳广播里的「移动档位」照抄客户端按键掩码（按 W 起跳就发「走」档），客户端会**持久**保持这个驱动状态 ⇒ 落地后停不下来 |
| `cc_stop_frame` | `off` | 方向键全松开那一拍补发一条「停」（位置取账本值，不外推） |
| `cc_action_frame` | `off` | 发蹲/跳这三类**带位置**的动作帧：55 号（跳跃广播）、39 号（特殊动画）以及顺带的坐骑帧 |

默认档唯一还发的移动相关下行是 54 号滞空状态（8 字节、不带 `position`）—— 治「按住空格人一直往上飘」靠的就是它，关掉 `cc_action_frame` 不影响。

另外两个相关键：`cc_foot_axis`（默认 `client`，控制步兵帧里前后/左右分量的正负号）与 `[cc] ladder_climb`（云梯斜面纠偏，默认 `off`，打开后服务端会按斜面改写上报的 Z）。

## 退回老口径

要在 `level.ini`（与 `Business` 同级、运行时读到的那一份）里写：

```ini
[move]
cc_move_mirror=on
cc_jump_state=mirror
cc_stop_frame=on
cc_action_frame=on
```

改完必须**结束本次游戏会话并重新启动**才生效：这些键在脚本导入时读一次，运行中改文件不会被看到。

不想改文件可以用环境变量，取值 `1`/`0`（`cc_jump_state` 用 `mirror`/`stop`），但必须在启动服务端之前设置：`T7_CC_INPUT_SYNC`、`T7_CC_MOVE_MIRROR`、`T7_CC_JUMP_STATE`、`T7_CC_STOP_FRAME`、`T7_CC_ACTION_FRAME`。`T7_MOVE_INI` 可以指定另一份 ini 的路径。

## 默认值是怎么定下来的（2026-10-07 实机收包记录）

- 四类回写帧全开时，一局 5 分钟里带位置的回写帧合计 289 条（55 号 84、39 号 160、坐骑 17），一次起跳落地就连发 3 条（落地沿 + 定时器补的两拍，间隔 200 ms）。
- 只关 `cc_stop_frame` 之前那一局：这条帧发了 26 条，紧邻的客户端上报位置横跳 12 次（−5.1 m / −6.2 m / 13.4 m）。
- 四个口子全关后，最新一局补停 0 条、动作帧 0 条，上报位置没有超过 9 m/s 的横跳。
- 纯走路（不碰空格、不碰 CTRL）时这几类帧本来就一条不发 —— 与「走路分后退只出现在跳/蹲之后」一致，说明成因在回写而不在按键处理。

单个键的判据细节写在 [`controls.py`](../src/Business/scripts/controls.py) 对应旋钮函数的文档串里；行为断言在 `scripts/verify_input_sync.py`（默认档在第 5b 节，老口径用环境变量显式打开后验证）。

## 已知代价

- `cc_action_frame` 默认 off 后，**别人**看不到你的蹲/跳动作。这些帧目前只回发给上报者本人，并不发给同场景的其他连接，所以关掉对多人观感没有净损失；要真正让别人看见，应改成按连接广播（写法参照 [`voice.py`](../src/Business/scripts/voice.py) 的会话遍历），而不是继续发给自己。
- `cc_move_mirror` 默认 off 后，Shift 冲刺和空手跑的**表现**不再由服务端驱动帧带出来；这两个功能要加回来不能简单打开该键。
- 契约档（`contracts.contract_mode()` 为真，供 `tests/python` 的 vendored 参考用例）下 `localReport` 本来就不下发任何镜像帧，上述键都不参与。
