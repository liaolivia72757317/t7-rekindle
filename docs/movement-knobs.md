# 移动开关（`level.ini` 的 `[move]` 段）

适用对象：客户端权威移动（`runtimeMovement` 为真）下的 Python 脚本。这五个键决定**服务端要不要往客户端回写移动状态**，全部有默认值，不写 `level.ini` 时行为与历史逐字节相同。

## 为什么需要这五个开关

客户端权威模式下，位置和朝向由客户端每帧上报，服务端只记一本账。问题是服务端发的**任何带 `position` 的移动报文**都会让客户端按回账本里的那个点，而账本只在收到上报时推进 —— 两次上报之间它最多多滞后一个上报间隔（外推上限 350 ms）。发得越频繁，人越容易被拽回旧点，玩家看到的就是「走一下退一下」「按 W 变后退」。

这五个键逐个关掉这些出口：总闸之外，把「平时报走/跑」「松手补停」「蹲跳带位置」三个口子分开管，出问题能一行一行退回去。

## 键与取值

| 键 | 默认值 | 含义 | 关掉/改动之后 |
| --- | --- | --- | --- |
| `input_sync` | `on` | 输入同步总闸：接受上报后是否做任何跳跃闸门、下蹲回声、镜像帧 | `off` = 只记账（位置/朝向/按键），一条帧都不发。下面四个键随之全部无效 |
| `cc_move_mirror` | `on` | 按键或快跑**变化**那一拍，跟发一条带方向的走/跑驱动帧（38 号） | `off` = 平时一条带方向的驱动帧都不发，走路完全交给客户端 |
| `cc_jump_state` | `mirror` | 蹲/跳广播报文里的「移动档位」字段怎么填 | `stop` = 恒为静止档、前后左右分量恒为 0，这个字段不再碰客户端的移动状态 |
| `cc_stop_frame` | `on` | 方向键全松开那一拍补发的「停」（位置取账本值，不外推） | `off` = 松手时服务端一个字都不发 |
| `cc_action_frame` | `on` | 蹲/跳这三类**带位置**的动作帧：55 号（跳跃广播）、39 号（特殊动画）、以及顺带的坐骑帧 | `off` = 三类全不发，只保留 54 号滞空状态（8 字节、不带位置）|

`cc_action_frame=off` 之后仍然保留的 54 号，是治「按住空格人一直往上飘」的那条 —— 它不带位置，不会把人拽回旧点。

另外两个相关键：`cc_foot_axis`（默认 `client`，控制步兵帧里前后/左右分量的正负号）与 `[cc] ladder_climb`（云梯斜面纠偏，`off` 时服务端不改写上报的 Z）。

## 实机跑通用的是这套

在 `level.ini` 里写下面这段（与 `Business` 同级的那一层，也就是启动器目录下运行时读到的那一份）：

```ini
[move]
input_sync=on
cc_move_mirror=off
cc_jump_state=stop
cc_stop_frame=off
cc_action_frame=off
```

改完必须**结束本次游戏会话并重新启动**才生效：这些键在脚本导入时读一次，运行中改文件不会被看到。

不想改文件也可以用环境变量，取值 `1`/`0`（`cc_jump_state` 用 `mirror`/`stop`），但它们必须在启动服务端之前设置：`T7_CC_INPUT_SYNC`、`T7_CC_MOVE_MIRROR`、`T7_CC_JUMP_STATE`、`T7_CC_STOP_FRAME`、`T7_CC_ACTION_FRAME`。`T7_MOVE_INI` 可以指定另一份 ini 的路径。

## 取值依据

2026-10-07 实机收包记录：`input_sync=on` 且下面四个键全默认时，一局 5 分钟里带位置的回写帧合计 289 条（55 号 84、39 号 160、坐骑 17），一次起跳落地就连发 3 条；只关 `cc_stop_frame` 之前那一局，松手补停发了 26 条，紧邻的客户端上报位置横跳 12 次（最大 13.4 m）。四个口子按上表关掉后，最新一局补停 0 条、动作帧 0 条，上报位置没有超过 9 m/s 的横跳。每个键的判据细节写在 [`controls.py`](../src/Business/scripts/controls.py) 对应旋钮函数的文档串里。

## 已知代价

- `cc_action_frame=off` 后，**别人**看不到你的蹲/跳动作。这些帧目前只回发给上报者本人，并不发给同场景的其他连接，所以关掉对多人观感没有净损失；要真正让别人看见，应改成按连接广播（写法参照 [`voice.py`](../src/Business/scripts/voice.py) 的会话遍历），而不是继续发给自己。
- `cc_move_mirror=off` 后，Shift 冲刺和空手跑的**表现**不再由服务端驱动帧带出来；这两个功能要加回来不能简单打开该键。
- 契约档（`contracts.contract_mode()` 为真，供 `tests/python` 的 vendored 参考用例）下 `localReport` 本来就不下发任何镜像帧，上述键都不参与。
