# 近战伤害

本地 Python 战斗规则在命中成立、格挡判定通过之后计算伤害，普通攻击基础伤害为 20，冲刺攻击为 40。

`最终伤害 = 四舍五入(基础伤害 × 部位倍率 × (1 + 速度增伤))`

部位使用原生碰撞点相对目标脚底的高度：低于 0.6 米为腿脚（0.75 倍），0.6 至 1.5 米为躯干（1 倍），1.5 至 1.8 米为头部（1.5 倍）。超出身体高度的点按躯干处理。这是直立身体高度近似，并非骨骼命中盒；蹲伏和特殊动作需要后续接入对应姿态。

速度使用连续世界位置采样，计算双方相对速度在攻击者至目标方向上的接近分量。远离、横向移动和同向同速不增伤，每米/秒增加 5%，上限 50%。首次采样、跨对局、复活、超过 100 毫秒的采样间隔和超过 25 米/秒的异常位移不产生速度增伤；缺失或过期数据也不增伤。这里计算角色移动速度，不包含挥刀自身速度。

参数集中在 `src/Business/scripts/damage.py`。命中日志记录实际计算伤害、部位和接近速度。扣血受剩余生命限制，格挡不进入该伤害公式。
