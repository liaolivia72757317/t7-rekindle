# 启动器版本日志

## 0.1.0

- 启动、游戏设置与关于三页布局，固定版本信息和底部主操作。
- 在游戏设置页选择、浏览和检查游戏根目录，并兼容已有客户端程序目录。
- 玩家名称随会话传入登录、角色信息和场景消息。
- 目录与名称验证后自动保存；保留最近日志并提供诊断入口。
- 区分启动、运行、失败、取消和退出状态。
- 正常退出兼容客户端退出码 `0` 与 `4660`；其他退出码保留异常反馈。
- 关于页提供项目介绍、仓库、正式版本、CI 开发构建与问题反馈入口。
- 点击更新时优先查询 R2 镜像，失败时回退 GitHub Releases；显示版本比较与发行说明，支持应用内下载、取消及校验后的用户确认安装。
